## 🎯 Description

**Laurent Tools** est une application de bureau qui regroupe **6 outils essentiels** en un seul endroit :

| # | Outil | Description |
|---|-------|-------------|
| 1 | 🔐 **Générateur de mots de passe** | Crée des mots de passe sécurisés et aléatoires |
| 2 | 🧮 **Calculatrice** | Calculs rapides avec interface moderne |
| 3 | 📝 **Bloc-notes** | Prendre des notes et les enregistrer en `.txt` |
| 4 | 📦 **Compresseur ZIP** | Compresser et décompresser des fichiers |
| 5 | 🖼️ **Convertisseur d'images** | Convertir PNG ↔ JPG ↔ BMP ↔ WEBP |
| 6 | 🌐 **Test Internet** | Mesurer la vitesse de ta connexion |

---

## ✨ Fonctionnalités

- ✅ **Interface moderne** noir/cyan
- ✅ **6 outils** en un seul logiciel
- ✅ **Rapide et léger**
- ✅ **Fonctionne hors ligne** (sauf Test Internet)
- ✅ **Compatible Windows**

---

## 🛠️ Technologies utilisées

- **Python 3**
- **Tkinter** (interface graphique)
- **Pillow** (conversion d'images)
- **speedtest-cli** (test de vitesse Internet)
- **zipfile** (compression ZIP)

## 🚀 Installation

### Méthode 1 : Télécharger l'application

1. Va dans **Releases**
2. Télécharge **`LaurentTools.exe`**
3. Double-clique dessus pour lancer !

### Méthode 2 : Depuis le code source

```bash
git clone https://github.com/Laurent-Dev571/Laurent-Tools.git
cd Laurent-Tools
pip install pillow speedtest-cli
python tools.py
